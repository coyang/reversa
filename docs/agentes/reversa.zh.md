# Reversa（编排器）

**命令：** `/reversa`
**阶段：** 编排

---

## 🎼 乐队指挥

指挥不演奏任何乐器。他们掌握整部乐谱，告诉每个人何时进入、以何种顺序、何种节奏。没有指挥，每个乐手都会自顾自地演奏而无法彼此配合。有了指挥，一切化作音乐。

---

## 功能说明

中央编排器是最先登场也是最后退场的角色。它不写代码、不分析模块、也不生成规范。它掌握整部乐谱，知道谁需要在何时、以何种顺序、何种节奏进入。

没有它，每个智能体会自顾自地执行任务而无法彼此衔接。有了它，一切变得协调有序。

---

## 职责

- 检查分析是否正在进行（读取 `.reversa/state.json`）
- 首次会话：创建个性化的探索计划并展示给用户
- 后续会话：从上次中断的位置精确恢复
- **按顺序**逐一运行计划中的智能体
- 每个智能体完成后保存检查点
- 每一步完成后呈现简短摘要
- 当上下文即将耗尽时发出警告，并在停止前保存状态
- 检查是否有新版本可用，并低调通知

---

## Scout 完成后的特殊行为

Scout 完成后，Reversa 读取生成的 `surface.json` 并个性化第二阶段计划。计划不再是泛泛的"分析代码"，而是每个已识别模块对应一个任务：

```
- [ ] Archaeologist: 分析模块 `auth`
- [ ] Archaeologist: 分析模块 `orders`
- [ ] Archaeologist: 分析模块 `payments`
```

---

## 从不打破的规则

- 未经用户明确请求，绝不同时运行多个智能体
- 未经通知，绝不偏离已批准的计划顺序
- 绝不删除、修改或覆盖项目中已有的文件

---

## 如何激活

=== "Claude Code / Cursor / Gemini CLI"
    ```
    /reversa
    ```

=== "Codex 及不支持斜杠命令的引擎"
    ```
    reversa
    ```

要恢复中断的分析，只需再次激活即可。已保存的状态会被自动读取。
