# PDF Export Setup for Reversa MkDocs

This reference documents the PDF export options and their requirements.

## Plugin options

### Option 1: mkdocs-pdf-export-plugin (recommended)

**Installation:**
```bash
pip install mkdocs-pdf-export-plugin
```

**Configuration** (in `mkdocs.yml`):
```yaml
plugins:
  - pdf-export:
      verbose: true
      media_type: print
      enabled_if_env: ENABLE_PDF_EXPORT
      combined: true
      combined_output_path: ../reversa-documentation.pdf
```

**Build command:**
```bash
ENABLE_PDF_EXPORT=true mkdocs build --site-dir ../site
```

**Requirements:**
- Python 3.7+
- A browser engine for HTML→PDF rendering. The plugin auto-detects:
  1. WeasyPrint (`pip install weasyprint`) — best quality, no browser needed
  2. headless Chrome (chromium-browser or google-chrome) — fallback

**Known limitations:**
- Mermaid diagrams may not render correctly in PDF (they require JavaScript). Use static images as fallback.
- Very large documents (>200 pages) may timeout.

### Option 2: mkdocs-with-pdf

**Installation:**
```bash
pip install mkdocs-with-pdf
```

**Configuration:**
```yaml
plugins:
  - with-pdf:
      author: Reversa
      copyright: Generated by Reversa
      cover: true
      back_cover: true
      cover_title: System Documentation
      cover_subtitle: Generated from code analysis
      output_path: ../reversa-documentation.pdf
      enabled_if_env: ENABLE_PDF_EXPORT
      toc_level: 3
      toc_title: Table of Contents
      two_columns_level: 3
```

**Build command:**
```bash
ENABLE_PDF_EXPORT=true mkdocs build
```

**Requirements:**
- WeasyPrint (`pip install weasyprint`)
- On Linux: additional system packages:
  ```bash
  # Ubuntu/Debian
  sudo apt-get install build-essential python3-dev python3-pip python3-setuptools python3-wheel python3-cffi libcairo2 libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libffi-dev shared-mime-info

  # macOS
  brew install weasyprint

  # Fedora
  sudo dnf install redhat-rpm-config gcc python3-devel cairo pango gdk-pixbuf2
  ```

### Option 3: Pandoc fallback (no MkDocs plugins)

If neither plugin works, generate PDF directly from the markdown using Pandoc:

```bash
# Install Pandoc and TeX Live
sudo apt-get install pandoc texlive-xetex

# Combine all markdown files and convert to PDF
cd _reversa_sdd
cat architecture.md domain.md */requirements.md */design.md > combined.md
pandoc combined.md -o ../reversa-documentation.pdf \
  --pdf-engine=xelatex \
  --from=markdown \
  --toc \
  --highlight-style=tango
```

**Pros:** Works without MkDocs, fewer dependencies.
**Cons:** No nav, no search, no theme — plain document with TOC only.

## Mermaid diagram handling in PDF

Mermaid diagrams require JavaScript to render. PDF engines do not execute JavaScript. Solutions:

| Solution | Complexity | Quality | Notes |
|----------|-----------|---------|-------|
| **Pre-render as PNG** | Medium | High | Use `mmdc` CLI (`npm install -g @mermaid-js/mermaid-cli`) to convert .md to .png before build |
| **Use mermaid-filter with Pandoc** | Medium | Medium | Pandoc filter that renders mermaid blocks |
| **Skip diagrams in PDF** | Low | Low | Add a note: "See HTML version for architecture diagrams" |
| **Screenshot replacement** | Manual | High | Capture screenshots of diagram sections from HTML, insert as static images |

**Recommended approach for best results:**
1. Install mermaid CLI: `npm install -g @mermaid-js/mermaid-cli`
2. Before `mkdocs build`, scan for `.md` files containing ```` ```mermaid ```` blocks and pre-render them as PNG images
3. Replace the mermaid code blocks with `![Diagram](path/to/diagram.png)` references
4. Proceed with PDF build

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| `ModuleNotFoundError: No module named 'weasyprint'` | WeasyPrint not installed | `pip install weasyprint` |
| `OSError: cannot load library 'libcairo'` | Missing system library | Install cairo library (see OS-specific commands above) |
| PDF has blank pages where diagrams should be | Mermaid not rendered | Pre-render diagrams, or use `screenshot replacement` above |
| PDF is truncated after N pages | Timeout or memory limit | Split nav into smaller sections, build per-section PDFs |
| `mkdocs serve` works but `mkdocs build` fails | Missing plugin dependency | Verify all plugins listed in `mkdocs.yml` are installed |
| Chinese characters show as boxes | Missing CJK fonts | Install Chinese fonts: `sudo apt-get install fonts-noto-cjk` or `xelatex` with `\usepackage{ctex}` in Pandoc fallback |
